## Methodology & honest limits

- **Chains** = the toolkit reads a shared Slots class makes (`self.tk.<A>.<b>`, an engine instance's members), resolved statically against both libraries' sources — see `compare_panel_surface.py`'s docstring for what hides or guards a call.
- **Option boxes** = distinct slot methods whose body references `.option_box.`; **controls** = `.add(` calls minus `Separator`s.
- **Limits:** resolution proves a name and a signature, not behavior — it cannot see whether an operation does on Blender what it does on Maya. The only true "feels seamless" test is running both.
